## Integration model decision: coherent whole-v2 RC

A task-only split was evaluated and rejected. The evidence:

1. **The task is the foundation layer of uncommitted v2 code.** V2's
   `agent_cockpit.rs` cannot compile without the task's `revision` column
   (migration 11), `DraftStatus::{Sending, Syncing}` variants, and the
   `map_draft` visibility change. V2's `scheduled.rs` is built on the task's
   `timefmt` and carries a regression test spanning task files.
2. **The browser layer is genuinely fused.** `dashboard.js`'s
   `openComposerFromDraft`/`sendComposer`/`closeComposer` mix revision-bound
   flow (task) with the composer redesign (v2) inside the same function
   bodies, calling v2 DOM ids and helpers; the SvelteKit
   ComposerDrawer/UndoToast/cockpit stack is the task's UX surfaced through
   v2 chrome. Extracting task hunks alone leaves dangling calls.
3. **Contract/test-time coupling.** `contract_drift.rs` (v2) pins the schema
   that the task's contract changes modify; the regenerated SvelteKit bundle
   is a single artifact reflecting both bodies of work.
4. **Roughly 80% of files separate cleanly, but the remaining 20% carry the
   semantics.** A fabricated task-only branch would need hand-written stub
   code in `dashboard.js`, `models.rs`, `lib.rs` (×2 crates), the web bundle,
   and the contract schema — producing a tree that never existed, was never
   tested, and would diverge from the canonical state this RC must audit.

Therefore this RC packages the complete v2 working state (HEAD `53347ab` +
all legitimate dirty/untracked project changes) as one coherent 0.13.0
release candidate.

## Version choice

0.13.0 (minor bump from 0.12.8) is correct under semver: substantial additive
surface (agent identities, cockpit, webmail, rules endpoints, new CLI/MCP
draft tools, new draft statuses and contract fields) with backward-compatible
JSON shapes; no removals or renames of existing contract fields, so no major
bump or new contract schema id is required. Interim 0.12.6–0.12.8 were
untagged internal bumps.
