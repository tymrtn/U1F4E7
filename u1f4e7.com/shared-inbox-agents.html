Shared inbox agents

Add an agent to the inbox your team already uses.

Support@, ops@, editor@, hello@ — the address stays the same. Humans keep working as before. Envelope gives the agent structured access, draft approval, reviewable rules, and a cockpit so everyone can see what happened.

Get the repoCommercial license
# Watch a shared inbox
envelope watch --account support@example.com --json

# Preview rules before moving anything
envelope rule preview --account support@example.com --limit 100 --json

# Draft first, send after approval
envelope draft create --to customer@example.com

The workflow does not change.

The mailbox is still the shared workspace. Envelope does not ask the team to move to a new app or route mail through a new provider. The agent joins the existing flow and works under human review.

What the agent can do

  • Watch for new mail
  • Extract codes and confirmations
  • Draft replies
  • Suggest cleanup rules
  • Export evidence bundles

Built for mixed human/agent ownership

Draft approval

The agent writes; a human approves, edits, or discards.

Reviewable rules

See affected messages before a cleanup rule moves anything.

Audit trail

Rule runs, drafts, watches, and send decisions are visible instead of implicit.
